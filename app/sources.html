Methods and notes

  • No estimates. Every figure is a published value. Where a chart needs a value the source does not publish, the chart leaves it out rather than filling it in.
  • Rounding. Tables show full values; charts round for labels (for example 123,975,371 people is shown as 124.0m). Rounding never changes a value by more than the last digit shown.
  • Currency. GDP, trade and GDP per capita are in current US dollars, as the World Bank publishes them. Dollar figures move with the yen–dollar rate; see the Economy page for why that matters.
  • Unemployment. The modelled ILO estimate, as a share of the total labour force. Japan's own Labour Force Survey publishes a similar series monthly.
  • Age structure. The 15–64 share (58.8% in 2024) is the remainder after the published 0–14 (11.4%) and 65+ (29.8%) shares.
  • Trade balance. Exports minus imports of goods and services, in current US dollars, computed from the published series.

About this site

Japan in Figures is an original site, designed and written for this bounty. It is plain static files — HTML, CSS and JavaScript with no build step and no network request — so it opens in any browser from its own files, on a desktop and on a phone.

The charts are drawn in the browser from the same numbers the tables print, using the site's own chart code (charts.js). The data lives in data.js; the controls in app.js.

Corrections: if a figure on this site disagrees with its stated source, the source is right and this site should be fixed. Every page names the source to check against.
